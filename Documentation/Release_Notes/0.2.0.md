## Carried forward from 0.1.x

Open items, none of them regressions. Recorded here so the cycle starts with
them visible rather than rediscovered.

- **`[workspace.dependencies]` for internal crates.** Twelve version
  requirements are twelve edits per bump. Moving them makes it one.
- **`ucal-cosmo` quadrature converges at O(h).** The interval extension is
  first-order, so halving the width costs twice the panels. A mean-value form
  would be O(h²), but it needs a *signed* rational interval type, since the
  derivative's bound goes negative and `Ratio` is non-negative by construction
  (Rule Z applied to rationals). Worth doing only if the arithmetic width ever
  becomes the binding constraint — at the default depth it is 40× smaller than
  the parameter width, so today it is not.
- **Titan has no anchor** and will not get one by invention. It needs a
  published convention to cite, or it stays structurally complete and unusable
  for dating (GE-3).
- **`z_of_t` bisection budget.** Sixty-four halvings of `[0, 10000]` resolve `z`
  to ~5e-16, which is still tens of seconds of cosmic time. A one-tick
  tolerance returns `UCAL-E0071`; that is honest, and it is also a ceiling
  nobody has tried to raise.
