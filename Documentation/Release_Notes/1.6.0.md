# 1.6.0 — UNRELEASED

In development on the `1.6.0` branch. `main` carries the released 1.5.0 line.

## The goal of this cycle: the mechanism without a wire

1.5.0 found five defects and four of them were the familiar shape — a claim with
no mechanism. The fifth was worse and is the one worth building a cycle on:

> `check-docs`' worked-examples check was **correct and unrun in CI for four
> releases.** It printed `--    worked examples not checked: target/release/ucal
> is absent` and moved on. Its own comment in `xtask/src/main.rs` warns that a
> check which silently skips is how a stale file survives.

A claim with no mechanism is findable by reading the claim. A **mechanism with no
wire** is not: the check exists, it is written correctly, it passes review, it
prints something on every run, and it is testing nothing. It came to light by
accident, because a frame committed into the documentation happened to make the
check fail locally in the one configuration where it had something to say.

That is the question for this cycle. **How many other checks are not connected to
anything, and how would anyone know?**

### Scope

**V1 — an audit of every check this project claims to run.** `xtask` has six
`check-docs` checks, twelve lints, a constants harness, a vector verifier and a
link checker; the workflows have four jobs across two files. For each: does CI
run it, does it run on the configuration that matters, and can it report success
without having examined anything?

The deliverable is a list, and the finding is whatever the list says. **Stop if**
the audit turns up more than can be honestly fixed in one cycle — then the
deliverable is the audit, and the fixes are scheduled.

**V2 — a check that no check can skip silently.** The specific mechanism, not the
general principle: every check reports `ok`, `FAIL`, or a *skip that fails CI*.
1.5.0's hole was a third state that looked like a pass. A skip is sometimes right
locally — the examples check genuinely cannot run without a binary — and never
right in CI.

**Stop if** it turns out some check must be allowed to skip in CI for a reason
that survives scrutiny. Then that reason is written down beside it, which is the
whole point.

**V3 — the argument-validation survey Z1.4 deferred.** `UCAL-E0001` is declared
as *malformed timestamp* and is what every CLI argument rejection in this binary
raises: `--color`, `--tick-sep`, and now `wallclock --once`'s frame size. That is
the D-A22 class, recorded in 1.5.0 and not fixed, because a fourth borrowed-code
correction in one cycle needed a survey rather than a spot fix.

This is the survey. One code for *an argument value is not valid*, a delta, and
every site moved onto it.

**Stop if** the survey finds the sites are not one class — if `--color bogus` and
a frame size out of range want different codes, that is a finding and the answer
is two codes with two reasons, not one code with a vague name.

### Done when

The audit exists, whatever it found is either fixed or scheduled with a reason,
and no check in this repository can report success without having run.

## Carried forward from 1.5.0

- **The three asks in [`CONTACT.md`](../CONTACT.md)** are open, wanted, and a
  condition on nothing shipping.
- **The 2.0 bundle**, decided in `ROAD-TO-2.0.md` and not scheduled: withdraw
  `bigint` from the public feature surface, move the data model to `Cow`, give
  `Measured` a sign, and implement §15.1 in the library.
- **§15.1 is `UNIMPLEMENTED`** for `ucal-body` (D-A20). Both loaders — body files
  and, since 1.5.0, anchor files — live in the binary and say so.
- **`--all-features` cannot build this workspace**, because it enables both
  backends and the guard fires. Three tools now want something the feature
  surface cannot give them: `semver-checks` needs `--default-features`, the MSRV
  job needs `--features tui` spelled out, and this. It is item 1 of
  `ROAD-TO-2.0.md` and it is getting louder.
- **A rounded parameter is a different calendar.** 1.5.0 gave body files a
  `derived:` form for the case where the exact value cannot be written down; for
  every other parameter the last digit an author types still chooses their
  intercalation.
- **`UCAL-E0001` is doing argument-validation duty** under a name that means
  *malformed timestamp*. V3 above.
- **Ten of the twelve derived calendars have no anchor**, which is the ordinary
  case and not a gap, for the reason `D5-titan-anchor.md` established.
- **[`GE-U4-walk.sh`](../Proposals/GE-U4-walk.sh) is built and unrun.**
- **W3, a third locale**, postponed with its reason recorded.
- **The signing key has no authority behind it that is not the author**, and the
  release checksums are not signed.
- **Eight commits in the history are unsigned**, permanently.
